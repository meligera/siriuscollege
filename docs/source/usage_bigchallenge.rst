Подключение к сети участников программы Большие Вызовы
=====

Адрес нашей сети **e5508544674ec5d8**

.. _connection_windows:

Windows
------------

Запускаем программу ZeroTier. Сервис должен появится в трее.

Нажимаем Join network, указываем адрес: **e5508544674ec5d8**

Обязательно ставим галку напротив параметра Allow Default Router Override

Передаем свой уникальный адрес организаторам для добавления в список разрешенных устройств

.. _connection_linux_bash:

Ubuntu 22.04 (cli)
------------

Подключаемся к сети

.. code-block:: console

    sudo zerotier-cli join e5508544674ec5d8

Передаем свой уникальный адрес организаторам для добавления в список разрешенных устройств

.. code-block:: console

    sudo zerotier-cli info

.. _connection_test:

Проверка работоспособности подключения
------------

Участики программы должны видеть устройтсва в сети 192.168.95.0/24

Подключение к вирутальным машинам производится через SSH

Пример:

.. code-block:: console

    ssh root@192.168.95.100
